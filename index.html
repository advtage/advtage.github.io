How a session starts

A lightweight look at the host → link → join loop. No invented app chrome — just the product flow.

  1. 1

    Host on your machine

    Open Advtage as the DM. The table runs locally — you are not renting a server for the night.

  2. 2

    Share a join link

    Send players a peer-to-peer web link. They join from the browser — nothing to install on their side.

    Join link https://…/join/<session>
  3. 3

    Keep playing

    Campaign files stay on your disk between sessions. Pick up where you left off without a cloud sync tax.

Host and join via link

Start the table on the DM app, share one link, and players drop in from a browser. Peer-to-peer — no account wall for joining the session.

Local campaign files

Maps, notes, and campaign data live on your machine by default. You own the files; nothing requires uploading your table to a host you don’t control.

Built for the DM table

Advtage is a DM-focused D&D 5.5e app — run the session tools you need at the table without bolting on a separate hosting stack.

No hosting fees
