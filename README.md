# Advtage site

Public GitHub Pages landing for [Advtage](https://dylan-griffin.github.io/advtage-site/).

- **Download** pulls the latest Windows NSIS installer from the public [`advtage-releases`](https://github.com/dylan-griffin/advtage-releases) repo
- Social links are placeholders until real URLs are added in `index.html`
- App source stays private in `dylan-griffin/advtage`

## Local preview

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## Pages

GitHub Pages serves `/` from the `main` branch.
